# Undrstnd Education

Built as my final university project with Amine Jguirim, **Undrstnd Education** is a learning platform that lets teachers create classrooms, upload documents, and lets students ask AI questions grounded in those documents.

## What it does

- **Classroom management.** Teachers create classrooms and invite students by university email; students join via a class code. Files can be uploaded, commented on, and downloaded.
- **RAG over uploaded files.** PDFs are split, embedded, and stored in Pinecone. The chat route runs a similarity search against the file namespace before calling the LLM, so answers cite the course material.
- **Student uploads.** Students can upload their own files and query them the same way.

## Stack

- **Frontend:** Next.js 14 App Router, React, Tailwind CSS, with `[locale]` routing for English and French.
- **Backend:** TypeScript, Prisma ORM, PostgreSQL.
- **AI:** LangChain + Pinecone for retrieval; Groq (`mixtral-8x7b-32768`) for generation.
- **Auth:** NextAuth.
- **Hosting:** Vercel.

## Outcome

The project placed first in the university competition. It is no longer actively maintained, but the code and a live demo remain available.
